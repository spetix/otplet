# OTPLet

This small blocklet permits to run otp generator on your favourite bar

## Getting Started

Create an otp setup with encrypted with your key.

### What you'll need

- otplet
  - gpg
  - gpgconf
  - gpgagent
  - otplet of cours

### How does it work

Store a seed with create option see [creating a new otp](./create)

Go to your OTP provider and obtain a new seed (normally a QR-code is presented).
Obtain the url from QR-code and launch the create command, specify the recipient for encryption and the place where the seed has to be stored.
In case the site provides parameters, normally:

- algorithm
- period
- issuer
- type 

Reconstruct the url in the form `otpauth://<type>/<site>:<user>??secret=<secret>&issuer=<issuer>&Algorithm=<algorithm>&digits=<number of digits>&period=<period>`
