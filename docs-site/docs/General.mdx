# General options

All the commands have a set of common flags:

| long      | short | default | meaning                            |
|===========|=======|==========|===================================|
| logLevel  | l     |    info  | default level of log entries      |
| logFile   | f     | `stdout` | the file used to store log        |
| logFormat | F     | text     | the format of the output          |
| store     | s     | otp.json | the file where the seed is stored |
